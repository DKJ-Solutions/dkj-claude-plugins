# Release notes v5.33.0 🚀

**Date:** 2026-10-26\
**Type:** Minor\
**For whom:** consumers of this product, and colleagues in the organisation -- one section each

## What changed

**Before you take the new `house-style.css`, check your own class names.** The house style now ships the
components that used to exist only in this repo's brand book: alerts, banners, panels, chips, tags, filter
chips, steppers, a search combobox, value boxes, stat rows, bill, compare and calc tables, date rows, figures
and prose. If your app already styles a class with one of those names, it now collides with the house class,
and your `check-house-style` gate names it. Rename your class, or drop it and use the house one. In MesoWise
that means `.chip`, `.help`, `.amount`, `.calc`, `.verdict` and `.question-head`.

**Fetch the house style from its new path.** Its files now live in `dkj-policy`, at
`plugins/dkj-policy/assets/house-style/`, and the `house-style` skill's pin table points there for v5.33.0.
A copy you already vendored stays valid, and the old path still serves every earlier tag. No action needed
until you take the new copy.

**Your hub gains a House style page.** Open the dkj-solutions plugin on the Plugins card to see every
token, the twelve themes and every component that this release's stylesheet ships, without leaving your own
hub. Your own pages and styling do not change.

**In phone-factory, a closed message that cannot reach Asana is now reported at session start.**
`closed-message-sessioncheck` now covers phone-factory too, as it already did the two stores, for the
`asana-closed-message` workflow only. It warns about a missing or drifted copy, a missing `ASANA_PAT`, and
an unstated `Get-ResolvesExemptMatchers`. `adopt-bwj-development` copies that workflow there and leaves
`asana-prio-label` out. No action needed.

**You can clear the session while an armed pull request ships.** When a backgrounded ship has armed its PR
`merge-when-green` and the checkout is back on `main`, the close-out now says plainly that the session can
be cleared. It still tells you to keep it open for what really dies with the session: an unarmed ship, a
subagent, a wait on this machine. No action needed.

**The Logbook shows at a glance which runs were quick.** Each finished run's time is green under 15
minutes, orange under 45 and red from 45 on, counting work time only. An abandoned `/sweep-issues` run now
drops off "Going now" after a day, like any other open run. No action needed.

**The house-style README gives `h2` as 18px**, which is what the stylesheet has used since October 25.

## What it is worth

- **One place for DKJ styling.** The brand book app was a second home for components that every
  DKJ-Solutions app was meant to take from the house style. That app is retired, and its components now ship
  with the plugin, so a new page starts from what already exists instead of being rebuilt by hand. Any
  repo can see them in its own hub.
- **A collision is caught by the gate, not by a customer.** An app whose own class shares a name with a new
  house class is told so by `check-house-style` before it merges. Without the gate, the collision would show
  up as a page that looks subtly wrong.
- **phone-factory joins the safety net the stores have.** One of its closed messages failed on a missing
  `ASANA_PAT`, and nothing reported it. The same failure now shows at the start of the next session.
- **What this release cost.** The clock started at 16:31:45 UTC. The cut ran the lint and all 170 suites in
  **2,099s** (16 lanes). In that time 17 commits landed on `main`, so the cut confirmed CI was green on the
  new tip and fast-forwarded. Its catch-up round then refused at once on an untracked `brandbook/` folder.
  The retired app's local `node_modules`, still held by a running dev server, had been left behind by the
  merge that removed the app. The folder was excluded locally, and the round was resumed on the certified
  commit without re-running the suites. The release commit landed at 17:10:57, for **39m 12s** to the cut,
  almost all of it the test gate that blocked the person cutting. Writing these notes and their lint and
  form check (196s), then the publish at 17:16:06 and both attachments, took the rest. The last asset landed
  at 17:16:20, for a total of **44m 35s**.
