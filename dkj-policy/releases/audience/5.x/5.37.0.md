# Release notes v5.37.0 🚀

**Date:** 2026-10-29\
**Type:** Minor\
**For whom:** consumers of this product

## What changed

**Merge-when-green now works in a private repo, and you have to act once.** Until now the merge-on-green
runner in a private repo never merged anything: its job token could not read the workflow run behind each
required check. Add `actions: read` under `permissions:` in `.github/workflows/merge-on-green.yml`, or delete
that file and run `adopt-ci-floor -Apply` again. Not sure? A re-run of `adopt-ci-floor` names a runner that
still lacks the scope under `[scope]`. A public repo needs no change.

**Every repo now gets the plugin's Toolbox.** A repo that ran its own hub through `OwnHub` gets the Toolbox
at its next session start, and its own server becomes its product there; it keeps working as it did. In a
DKJ-Solutions repo the session line asks you to delete the `OwnHub` (and `Product`) keys from
`Get-DevPreview`. Every other repo sees no change. See the
[hub README](../../../../plugins/dkj-policy/hub/README.md#one-look-in-every-repo).

**Your session check stops flagging a correct copy of the house style.** The `house-style` skill now pins
checksums that the tag beside them actually serves, written by the release itself, so a consuming repo whose
vendored stylesheet is right no longer gets a warning it has to clear. No action needed.

**Two cards side by side no longer make the page scroll sideways.** In the house style a `.grid-2` row now
shrinks like `.grid-3`, so a card holding one long line, such as a `code` command or an ellipsised
description, stays inside the page. A local `min-width: 0` workaround for this can go. Your app picks it up
with its next copy of `house-style.css`.

**A page's `h1` is never framed.** The house style now clears any border, outline, shadow and background on
an `h1`, and the rule says it stands on the page itself, never inside a card or box. Pages built on
`.page-column` also stack a little tighter. If your own layer framed the `h1` through a plain `h1` selector,
that frame goes with your next copy of the house style.

**The house style's specimens page now sits under dkj-policy.** It moved to
`/plugins/dkj-policy/house-style`, so a BWJ-Development toolbox now shows it too, with every token, theme and
component. A bookmark to the old address still lands.
