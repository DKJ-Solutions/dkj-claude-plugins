# Release notes v5.21.0 🚀

**Date:** 2026-10-15\
**Type:** Minor\
**For whom:** consumers of this product, and colleagues in the organisation -- one section each

Every DKJ-Solutions repo opens a dev preview at session start, plus the check-house-style gate and the awaiting-pull-external label

## What changed

**No action needed to update.** Two optional steps are named below: a Simple Browser route for the
placeholder preview, and a CI caller for the house-style gate.

### DKJ-Solutions repos: a dev preview opens at every session start

A repo with no `Get-DevPreview` of its own now gets a placeholder page at `http://localhost:4880/` (or the
next free port up to 4889) that says how to add a real preview
([#3047](https://github.com/DKJ-Solutions/dkj-claude-plugins/issues/3047)). To open it in VS Code's Simple
Browser, add `"localhost:4880": "simpleBrowser.open"` under `workbench.externalUriOpeners` in the repo's
`.vscode/settings.json`; the session-start line tells you when that route is missing. When your own
`Get-DevPreview` binds to `127.0.0.1` but the server it reuses listens on every interface, the line now
says `LISTENING ON ALL INTERFACES` ([#3041](https://github.com/DKJ-Solutions/dkj-claude-plugins/issues/3041)).

### DKJ-Solutions repos: the house style is checked for drift

A new session-start line reports a drifted copy of `house-style.css` or `house-theme.js`, a redefined
house token or class, or a retired token name such as `--muted` or `--good`, with file and line
([#3035](https://github.com/DKJ-Solutions/dkj-claude-plugins/issues/3035)). To block a pull request on the
same findings, add the few-line caller from the `house-style` skill page, which calls
`reusable-house-style.yml`. Answer a false positive with a reason in `Get-HouseStyleAllowlist`. Method
calls such as `.sort((a, b) => {` and spreads such as `{ ...meta, }` are no longer read as house classes
([#3040](https://github.com/DKJ-Solutions/dkj-claude-plugins/issues/3040)), so allowlist entries added for
those can go.

### A parking label for work waiting on another repo

`awaiting-pull-external` parks an issue until a pull request in another repo has been released and taken
here, where `awaiting-pull` came off at the upstream merge
([#3044](https://github.com/DKJ-Solutions/dkj-claude-plugins/issues/3044)). Run `adopt-triage-labels` for
the `gh label create` line.

### Smaller changes, no action needed

- `tidy-machine` now prints `git worktree remove` for a lane holding a finished branch, instead of a
  command that put the branch back in your primary checkout
  ([#3039](https://github.com/DKJ-Solutions/dkj-claude-plugins/issues/3039)).

## What it is worth

- **The house style now holds itself in place.** v5.20.0 made the brand book's v3 tokens available; this
  release adds the gate that reports an app drifting from them, so alignment no longer depends on someone
  reading the CSS by hand.
- **Every DKJ-Solutions repo has a preview from its first session**, so seeing a visual change no longer
  starts with somebody setting up a server.
- **What this release cost.** The clock started at 18:46:34 UTC. The cut (lint, all 161 suites in 226s,
  bump, commit, tag, push) finished at 18:51:40, **5m 06s**, all of it blocking.

## What was still open at this release

The per-app migrations to `house-style-v3` had not landed yet, so the new gate was expected to report
findings in those apps until each one moved.
