# Release notes v5.34.0 🚀

**Date:** 2026-10-27\
**Type:** Minor\
**For whom:** consumers of this product, and colleagues in the organisation -- one section each

## What changed

**In a store, re-copy `asana-closed-message.ps1` to have a reopened ticket move its Asana card back.**
When a GitHub issue linked to an Asana task is reopened, the card now goes back to `InDevelopment` and the
task is unticked, after the "reopened" message is posted. To take it, re-copy
`.github/scripts/asana-closed-message.ps1` and make sure your `Get-AsanaStageMap` names `InDevelopment`;
without that entry only the untick happens. A task on several boards is unticked but not moved.

**A sweep now carries on past a result you have to judge by eye.** `/sweep-issues` parks such a branch on
`origin` with `awaiting-review-dev` and a comment on what to look at, then picks up the next issue. The
close-out lists every parked branch with the `git checkout` line that shows it. Nothing is merged unseen. No
action needed.

**You can run a second sweep beside a running one on the same machine.** Open a detached worktree next to
your checkout, start Claude Code there and run `/sweep-issues`: it works in lane mode and leaves the fold
to the CI fold runner. See the `worktree-lane` skill.

**`ship-pr` tells you up front whether you can close the session.** Before its gates it prints a clearance
forecast: whether the session can be cleared once the PR is armed, or has to stay open until the merge and
the fold. No action needed.

**After switching Windows accounts, your next session starts with its product again.** A dev server left
running in a disconnected session now frees its port about a minute later. Where a port is still held, you
get the exact `Stop-Process` command instead of a bare process id.

**Your hub pages are shorter and drill down instead of scrolling.** Any page with more than four sections
is now an overview of cards, each opening a page of its own. That applies to the House style page, the Test
gate (overview, then a group, then a suite) and the SessionStart page. A page that still runs past your
window shows a warning at the bottom right, on every hub page including home and the release notes.

**Your hub home page has one Clock card** in place of the Test gate, Stopwatch and Logbook cards; all three
are one click further, on `/clock`. The airsquats banner only slides in when it is due and slides out once
ticked. No action needed.

**A recurrence of a recorded problem is logged as a comment, and the record stays closed.** The workflow
page used to say to reopen a `[RECORD]` issue, and nothing closed it again. An issue still waiting for its
first recurrence is reopened as before.

**Two smaller repairs, no action needed.** The `house-style` skill no longer stops a session on a correct
`house-theme.js` because it also remembers the page width. And the Logbook counts each issue once when two
sweeps ran side by side in one checkout.

## What it is worth

- **Backlogs move without someone in the chair.** A sweep no longer stops at the first visible result, and
  a second sweep can run beside the first. Visible work queues up for review instead of halting the run,
  so one review moment covers a whole batch.
- **The Asana board keeps itself honest.** A reopened ticket used to show as finished on the board while
  development had resumed. It now moves back on its own, so the board and GitHub agree without anybody
  dragging a card.
- **Shared machines stop losing their product.** Switching Windows accounts used to leave the next session
  without its dev server until somebody found and killed the old process by hand.
- **What this release cost.** The clock started at 11:36:12 UTC. The cut ran the lint gate and all 170
  suites in **297s** (18 lanes) and landed the release commit at 11:42:15, for **6m 03s** to the cut. No
  merge landed during the gates, so no catch-up round was needed; at v5.33.0 that race and its recovery
  took the cut to 39 minutes. The tail is the long part this time: the release-notes commit landed at
  12:43:54, about an hour after the cut, with its lint and form check taking 48s of that. The Release was
  published and the last asset landed at 12:44:03, for a total of **1h 07m 51s**.
