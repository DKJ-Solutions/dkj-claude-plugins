# Release notes v5.35.0 🚀

**Date:** 2026-10-27\
**Type:** Minor\
**For whom:** consumers of this product

## What changed

**Your trunk now follows origin by itself.** At every session start, a checkout that stands clean on its
trunk and is only behind origin is fast-forwarded before the session checks run. Need every checkout on your
machine at once? Run the new `sync-trunk` skill with `-AllCheckouts`. A checkout on a branch, with
uncommitted changes or with local commits that origin lacks is never touched. No action needed. To turn the
session-start step off, set `DKJ_TRUNK_AUTOSYNC=0`.

**On a machine shared between Windows accounts, your hub stays up.** It no longer stops two minutes after a
session start in a disconnected session, or after you switch to another account and back. A server is now
stopped only when several sources agree that its session is gone. No action needed.

**The airsquats banner tells you when the hub is offline.** When its server stops answering for about 30
seconds, the banner says "hub offline, this hour is not counted" instead of counting towards an hour that
will never be recorded.

**Your next release note has one section, *What changed*.** The two organisational sections nobody filled
in are gone, and so is the `Get-ReleaseNoteSections` seam that switched them off. A repo that still defines
the seam changes nothing. No action needed.

**A release's page shows its points as cards, at most three across**, instead of one long column.

**`new-branch` refuses a second branch for an issue that already has one on origin.** You get the existing
branch's name, and resuming it still works, so two sweeps can no longer build competing fixes for one issue.

**A session no longer opens with a house-style warning it cannot clear.** Between a house-style change and
the release that carries it, a correct copy of the house-style files used to be flagged anyway.

**A repo before its first release gets an empty release-notes page in the hub instead of a build error.**
Its first cut also follows the tier gate's own advice: `-Bump minor` cuts v0.1.0.

**The hub's Repository card is now called GitHub** and carries the GitHub logo. `/repository` still works.
