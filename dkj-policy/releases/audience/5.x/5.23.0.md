### DEPLOY: feat/3088-brandbook-v0-2-0 · 20261017-150058Z

The `house-style` skill now fetches from the brand book's `v0.2.0` release, and its first step says that
every page a repo's dev server serves opens with the breadcrumb bar, starting at **Repo dashboard**
([#3088](https://github.com/DKJ-Solutions/dkj-claude-plugins/issues/3088),
[#3089](https://github.com/DKJ-Solutions/dkj-claude-plugins/issues/3089)). An app that takes the new copy
gets greyer middle steps (`--primary-4`..`-6`) in every theme, a theme picker whose dots come from the
stylesheet instead of the script, and the `.breadcrumbs` / `.breadcrumbs-bar` classes. No token was
renamed or removed, so nothing in an app's own layer has to change. The placeholder Repo dashboard this
plugin serves takes the same copy.

**Score:** 2

#### What makes this deploy extra special

A session doing visual work in a DKJ-Solutions repo now meets the breadcrumb rule in the skill it
loads first, rather than only in the brand book's README, so new dev-server pages get the bar from the
start.

**Score:** 2

### DEPLOY: feat/3090-dev-pages-breadcrumb-bar · 20261017-154017Z

The placeholder Repo dashboard the `dkj-solutions` plugin serves, in every repo without a dev preview of
its own, now opens with the house breadcrumb bar: one crumb, **Repo dashboard**, sticky at the top
([#3090](https://github.com/DKJ-Solutions/dkj-claude-plugins/issues/3090)). It follows the rule the
brand book's `v0.2.0` sets for every page a dev server serves. Nothing in a repo's own layer changes.

**Score:** 1

#### What makes this deploy extra special

This repo's own connector dashboard carries the same bar, so both dev-server pages here now take the
Repo dashboard form block for block.

**Score:** 1

---

### DEPLOY: feat/3084-brandbook-v0-1-0 · 20261017-092629Z

The `house-style` skill now fetches from the brand book's `v0.1.0` release, which brought the four
`house-style-v1`..`-v4` tags together ([#3084](https://github.com/DKJ-Solutions/dkj-claude-plugins/issues/3084)).
The two files there are byte-identical to `house-style-v4`, so the checksums and both vendored copies stand.

**Score:** 1

#### What makes this deploy extra special

Nothing a DKJ-Solutions app takes changes: the bytes are the same. It prevents a failure that has not
happened yet: the brand book deleting its `house-style-v*` tags would otherwise leave every installed
copy of the skill fetching from a tag that no longer exists.

**Score:** 1
