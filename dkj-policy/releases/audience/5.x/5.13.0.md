# Release notes v5.13.0 🚀

**Date:** 2026-10-03\
**Type:** Minor\
**For whom:** consumers of this product, and colleagues in the organisation -- one section each

Release version 5.13.0

## What changed

**Nothing breaks on update.** Two items ask for a one-off action, and only if they apply to you;
everything else works the moment you update.

### Store repos on BWJ: refresh your `asana-mirror` copy once

Run step 1 of `adopt-dkj-policy-bwj`, which diffs your copy of `asana-mirror.ps1` against the new
template rather than overwriting it. Two things arrive with it:

- **The go-live block reaches the Asana task by itself.** When the issue closes, the mirror posts one
  closed message on the task with the block's sections, `TE BEKIJKEN OP` first, and the headings, links
  and line breaks intact. You no longer paste the block by hand, and the separate *ready to test*
  comment is gone ([#2700](https://github.com/DKJ-Solutions/dkj-claude-plugins/issues/2700)).
- **Cards stay on your own board.** Where `ASANA_PROJECT_GID` is set, the stage move reads only that
  board, so a task is no longer moved on a colleague's workload board, and a task added to your board is
  staged as `report-issue` promises
  ([#2717](https://github.com/DKJ-Solutions/dkj-claude-plugins/issues/2717)).

### Your three waiting labels have new names

`needs-info` is now `awaiting-more-info`, `awaiting-recurrence` is `awaiting-first-recurrence`, and
`record` is `awaiting-more-recurrences`. Nothing breaks: every gate, pickup route and board reads the
old names too. To rename your labels in place, issues and all, run `adopt-triage-labels`; it prints one
`gh label edit` per label ([#2723](https://github.com/DKJ-Solutions/dkj-claude-plugins/issues/2723)).

### Session start now says when you are current

You now see *dkj plugins are up to date: this session runs v5.13.0* when nothing is waiting, next to
the warning you already got when a release is out. When the check cannot run (offline, a timeout), it
still says nothing, so it never claims "up to date" without having looked
([#2702](https://github.com/DKJ-Solutions/dkj-claude-plugins/issues/2702)).

### New for DKJ-Solutions repos: `dkj-policy-dkjs`

Enable it and your pages, reports and Artifacts start from one house style: a set of design tokens for
light and dark, and a base stylesheet. `adopt-dkj-policy` writes its `CLAUDE.md` import for you, and the
session check warns while the line is missing. That now holds for every `dkj-policy-*` extension, not
only BWJ's ([#2695](https://github.com/DKJ-Solutions/dkj-claude-plugins/issues/2695),
[#2697](https://github.com/DKJ-Solutions/dkj-claude-plugins/issues/2697)). Nothing changes for a repo
that does not enable it.

### `phone-factory` is admitted to the BWJ extension

`adopt-dkj-policy-bwj` and `report-issue` run there for ticket handling instead of refusing at step 0.
The Shopify chapters do not apply, there is no `CRO` label, and requests from its Asana board follow
step 8 like the two Shopify stores
([#2705](https://github.com/DKJ-Solutions/dkj-claude-plugins/issues/2705),
[#2712](https://github.com/DKJ-Solutions/dkj-claude-plugins/issues/2712)).

### Smaller fixes, no action needed

- **`fold-on-merge` folds in a repo that declares no plugins.** It used to fail with *You cannot call a
  method on a null-valued expression* ([#2693](https://github.com/DKJ-Solutions/dkj-claude-plugins/issues/2693)).
- **A tier 0 written as `N/A` is refused at `open-pr` and by the `branch-entry` check**, so it is fixed
  on the branch rather than on the trunk ([#2709](https://github.com/DKJ-Solutions/dkj-claude-plugins/issues/2709)).
- **`update-plugins` stops claiming updates it did not make.** A no-op run now ends with
  `0 plugin(s) updated, 5 already at the latest version`.
- **Every session loads about 1,450 fewer tokens** before its first assignment: Chris's persona moved
  its reasoning to his on-demand manual. No rule changed.
- **The go-live comment's last paragraph renders as text**, not as a bold heading
  ([#2701](https://github.com/DKJ-Solutions/dkj-claude-plugins/issues/2701)).
- **`report-issue` handles a ticket that lives on another Asana board**: it skips the writes Asana
  refuses and names the one step left to a person
  ([#2699](https://github.com/DKJ-Solutions/dkj-claude-plugins/issues/2699)).
- **The workflow page now says you write the `#### Pull Request` title**, which `open-pr` already
  required.

## What it is worth

- **One less manual hand-off between developer and colleague.** The go-live block used to be copied
  into Asana by hand at every close; the mirror now posts it, in one message, without a person in the
  loop.
- **Less risk on boards this repo does not own.** The mirror could move cards on a colleague's workload
  board; it now stays on the store's own board.
- **A third store runs the shared ticket workflow** (`phone-factory`), with its reach stated rather than
  left open, and DKJ-Solutions apps get a shared house style instead of each rebuilding one.
- **Cheaper sessions everywhere.** Roughly 1,450 tokens leave every session's always-on context, paid
  back on every session in every consumer.
- **Measured cost of this release:** clock started 09:28:18; the cut (lint, all 153 suites in 650s on
  4 lanes, bump, commit, tag, push) landed its release commit at about 09:40:40, **~12m 22s**, all of it
  blocking. Writing these notes plus the note-tree gate (lint only, 53s) followed, then the publish and
  both attachments: the last asset landed at 09:42:43, **14m 25s end to end**.
