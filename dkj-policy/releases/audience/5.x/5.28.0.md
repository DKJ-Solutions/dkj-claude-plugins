# Release notes v5.28.0 🚀

**Date:** 2026-10-22\
**Type:** Minor\
**For whom:** consumers of this product, and colleagues in the organisation -- one section each

## What changed

**DKJ-Solutions apps open at full width now.** If your app runs `house-theme.js` and sets no
`data-width-default`, its pages open at **full** width instead of the 1080px fluid column. A width a user
picked in the settings panel still wins. To keep the old look, set `<html data-width-default="fluid">`.

**Your Repo hub is two pages.** `/` is your repo's home page: its name, its products, a link to **About
this repo**, and in a DKJ-Solutions repo the **Brand book**. `/about` holds the rest: your repo's own pages,
the general pages (Artifacts, Issues, Release notes, SessionStart) and its facts. No action needed. If your
repo serves its own hub (`OwnHub = $true`), build its new form from the house-style README and
`patterns/repo-dashboard.html` plus `patterns/repo-about.html`.

**A repo with its own hub can link its product too.** Add a `Product = @{ Command; Ports; Path; Requires;
WaitSeconds }` block beside `OwnHub = $true` in `Get-DevPreview`, and the session start hands out both links
on one line:
`Repo hub: http://localhost:4870/ (started) -- product: http://localhost:5173/brandbook/ (started)`. A
product that cannot start is named beside the hub's link and does not stop the hub.

**After a plugin update, the Repo hub link works again on its own.** A hub server left over from the
previous version is stopped and restarted on the same port, and the session's line says
`(restarted: it ran another plugin version)`. Before, the link could fail with `ERR_TOO_MANY_REDIRECTS`
until you stopped the old server by hand.

**The brand book no longer shows a Repo hub section.** The hub's form lives in the house-style README and
its two patterns instead.

**Parked recurrence issues close right away.** An issue parked under `awaiting-recurrences-first` is closed
as `not_planned`, keeping its label and `[RECORD]` prefix, so your open list holds only work. No action
needed.

## What it is worth

- **A repo's hub is a front door now, not a list of tools.** Anyone opening the hub sees what the repo
  is and what it makes before the developer pages, which is what makes the hub useful to someone who is
  not the developer.
- **One less manual step after every update.** The stale hub server that had to be found and stopped by
  hand after the move to v5.27.0 now restarts itself.
- **What this release cost.** The clock started at 10:53:06. The cut (lint, all 164 suites on 27 lanes, the
  brand book build, bump, commit, tag, push) finished at 11:00:35, **7m 29s**, all of it blocking.
